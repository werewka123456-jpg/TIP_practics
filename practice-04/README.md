### 6.3. Обновление задачи

В файле `task-service.js` реализована функция `updateTask(tasks, id, title, priority)`.

**Особенности реализации:**
- Функция не мутирует исходный массив, а создает его копию через `[...tasks]`.
- Для проверки названия и приоритета переиспользуется логика из `createTask`. Это позволяет избежать дублирования кода.
- При обновлении сохраняются исходные поля `id` и `completed` благодаря использованию spread-оператора (`...`).
- Если задача с указанным `id` не найдена или данные некорректны, возвращается `{ ok: false, error }`.

**Проверено:** Изменение названия и приоритета невыполненной задачи, сохранение статуса `completed`, обрезка пробелов, обработка отсутствующей задачи и некорректных данных. Исходный массив остается неизменным.

### 6.4. Чистая валидация формы

В файле `form-validation.js` реализована функция `validateTaskDraft(draft, tasks, editingId)`.

**Особенности реализации:**
- **Чистота:** Функция не обращается к DOM, не читает `localStorage` и не изменяет переданные объекты.
- **Режим создания:** ID проверяется на пустоту (пустая строка отклоняется до преобразования в `Number`), на положительность, целочисленность и уникальность в массиве `tasks`.
- **Режим редактирования:** Значение `draft.id` игнорируется. Используется `editingId`, проверяется, что такая задача действительно существует.
- **Название:** Приводится к строке, очищается от пробелов с помощью `trim()`, проверяется на длину (от 1 до 100).
- **Приоритет:** Строго проверяется на соответствие одному из трех значений: `low`, `medium`, `high`.
- Возвращает объект с ошибками (только для неверных полей) либо успешный объект со значениями `{ id, title, priority }`.

**Проверено:** Функция проходит граничные случаи (пустые строки, некорректный тип данных, занятые ID) и не обращается к `document`.

**Критерий готовности выполнен:** Объяснено различие между нативной HTML-проверкой (проверяет структуру), прикладным правилом (проверяет бизнес-логику, например, пробелы) и обработкой ошибок парсинга JSON (через `try/catch`).
